# Project Submission

This repository contains two projects submitted for evaluation. Each project is organized in a separate folder and includes its own README file with detailed information about the project.

## Projects

### 1. Self-Healing NGINX Server

A self-healing server project focused on monitoring and automatically recovering an NGINX server when issues are detected.

**Project folder:** [`Self-Healing-NGINX-Server`](./Self-Healing-NGINX-Server)

**Documentation:** [`Project README`](./Self-Healing-NGINX-Server/README.md)

---

### 2. ArgoCD GitOps Demo

A GitOps-based Kubernetes deployment project using Argo CD and Kubernetes manifests.

**Project folder:** [`argocd-gitops-demo`](./argocd-gitops-demo)

**Documentation:** [`Project README`](./argocd-gitops-demo/README.md)
